# 我的工作台 · 产品说明

## 1. 产品定位

一个**手机端优先**的个人生活管理工作台。所有数据保存在浏览器本地（LocalStorage），无需登录、无需联网，打开即用。

## 2. 首页（今日 / 工作台）

### 2.1 顶部时钟区
| 元素 | 说明 |
| --- | --- |
| 实时时钟 | 时:分 大字号，秒数小字，每秒刷新 |
| 日期 | `10月15日 周三` 格式 + 农历风格的问候语（早上好/下午好…） |
| 一句话激励 | 每天自动更换（按日期序号取模），支持手动「换一句」 |
| 打卡按钮 | 大号主按钮「今日打卡」，今日已打卡则显示 ✓ 已打卡 + 连续天数 |
| 本周打卡条 | 7 个小圆点，显示本周每天打卡状态 |

### 2.2 统计卡片（5 张）
1. **事项提醒** — 今日到期 + 以过期未完成的事项数
2. **本月已完成待办** — 本月内完成的 todo 条数
3. **连续打卡天数** — 从今天/昨天往前推的连续天数
4. **本月支出汇总** — 本月支出合计（¥），显示较上月增减
5. **待处理事项** — 未完成 todo + 未完成提醒 + 待处理储物借用

### 2.3 快速跳转
- 分类事项提醒 → `/reminders`
- 待办清单 → `/todos`
- 习惯打卡 → `/habits`
- 记账本 → `/ledger`
- 储物清单 → `/storage`
- 灵感库 → `/ideas`
- 周度复盘 → `/review`

## 3. 功能模块

### 3.1 分类事项提醒 `/reminders`
按分类（工作 / 生活 / 健康 / 学习 / 其他）分组展示提醒事项。每条含标题、日期、时间、备注、完成状态。
- 新增 / 编辑 / 删除 / 完成勾选
- 顶部筛选：全部 / 今天 / 已过期 / 已完成
- **每日重置**：过期状态按当天日期实时计算

### 3.2 待办清单 `/todos`
- 快速输入框（回车即添加）
- 优先级：高 / 中 / 低
- 可设置截止日期
- 今日 / 全部 / 已完成 三个视图
- 完成时间戳记录（用于「本月已完成」统计）
- **累积记录**：不会每日清空

### 3.3 习惯打卡 `/habits`
- 内置习惯模板（早起 / 阅读 / 运动 / 喝水 / 早睡 …）可自定义
- 每个习惯显示：名称、图标、连续天数、近 7 天打卡状态
- 点击圆点即可打卡/取消（按日期记录，可补卡近 7 天）
- **每日重置**：勾选状态按当天日期判定

### 3.4 记账本 `/ledger`
- 记一笔：金额、类型（支出/收入）、分类、备注、日期
- 分类：餐饮 / 交通 / 购物 / 居家 / 娱乐 / 医疗 / 学习 / 其他
- 顶部汇总：本月支出、本月收入、本月结余
- 最近记录列表，按日期分组，可删除
- **累积记录**

### 3.5 储物清单 `/storage`
记录物品存放位置，解决「东西放哪了」。
- 物品：名称、分类、位置（如「卧室衣柜第二层」）、数量、备注
- 搜索 + 分类筛选
- 借用状态标记（借出 / 归还），借出计入「待处理事项」
- **累积记录**

### 3.6 灵感库 `/ideas`
- 一句话灵感 / 想法 / 待读清单
- 标签分类：想法 / 待读 / 待看 / 收藏
- 卡片流展示，可标星、可转成待办
- **累积记录**

### 3.7 周度复盘 `/review`
- 按自然周（周一起）统计：待办完成数、打卡次数、支出金额、新增灵感数
- 记录本周「做得好」「待改进」「下周目标」三项文字
- 历史周复盘可翻看（上一周 / 下一周）
- **每周重置**：每周一份独立记录

## 4. 数据模型（LocalStorage）

```
wb.todos      : Todo[]      { id, title, note, priority, due, done, doneAt, createdAt }
wb.reminders  : Reminder[]  { id, title, note, category, date, time, done, createdAt }
wb.habits     : Habit[]     { id, name, emoji, color, records: string[] }  // 'YYYY-MM-DD'
wb.ledger     : Entry[]     { id, amount, type, category, note, date }
wb.storage    : Item[]      { id, name, category, location, qty, note, lentTo, lentAt }
wb.ideas      : Idea[]      { id, text, tag, starred, createdAt }
wb.reviews    : Record<weekKey, {good,bad,next,updatedAt}>
wb.meta       : { lastOpen: 'YYYY-MM-DD' }
```

统一 key 前缀 `wb.v1.`，便于版本迁移。

## 5. 交互与视觉

- **移动端优先**：最大宽度 480px 居中，桌面端呈现为手机屏效果（带圆角与阴影）
- **底部 Tab 栏**：今日 / 待办 / 打卡 / 我的（其余模块从快捷入口进入）
- **主题**：暖橙珊瑚 `#F97362` 主色 + 奶油米白背景，柔和圆角 20-24px，Bento 卡片网格
- **字体**：Nunito Sans（圆润友好）
- **动效**：页面切换 fade、卡片 stagger 入场、打卡按钮弹性反馈
- 所有点击元素有 `cursor-pointer` 与按压反馈
- 深色模式变量保留

## 6. 每日重置策略

| 模块 | 策略 |
| --- | --- |
| 打卡 | 按日期判定，今天未打卡即未完成（历史记录永久保留） |
| 提醒事项 | 过期状态按今天实时计算 |
| 待办 | 累积；「今日视图」按截止日期=今天过滤 |
| 记账 | 累积；「本月」按日期过滤 |
| 储物 / 灵感 | 累积 |
| 周复盘 | 按周边界自动切换 |
| 激励语 | 按日期自动更换 |
