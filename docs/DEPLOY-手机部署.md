# 手机上怎么用「我的工作台」

这个应用是**纯前端 + 本地存储**的：不需要服务器、不需要数据库、不需要登录、不需要联网。
所以"部署到手机"其实只有两种思路：**把文件放进手机**，或者**把它放到网上用手机浏览器访问**。

已经准备好两个产物，任选一个：

| 产物 | 大小 | 适合 |
| --- | --- | --- |
| `工作台.html`（单文件） | 约 710 KB | 不想折腾，直接传手机 |
| `工作台-托管版.zip` → 解压得 `dist-web/` | 约 570 KB | 想随时随地打开、换手机也不丢 |

两个版本都用 **HashRouter**（网址形如 `.../#/todos`），所以**刷新不会 404，也不需要配置任何服务器重写规则**，放到任何静态托管的根目录或子目录都能直接跑。

---

## 方案一：单文件直接放进手机（最快，零成本）

`工作台.html` 是**自包含单文件**：JS / CSS / 图标全部内联，断网也能用。

### 安卓

1. 把 `工作台.html` 通过**微信文件传输助手 / QQ / 数据线 / 网盘**传到手机
2. 在「文件管理」里找到它，点击 → 选择用**浏览器打开**（Chrome / Edge / 夸克 / 系统浏览器都行）
3. 打开后点浏览器菜单 → **添加到主屏幕**，桌面就有图标，点开像 App 一样

> 文件别放"下载"目录（容易被清理），建议移到「文档」目录并长期保留。
> 数据跟着这个文件的路径走，**文件位置变了数据就看不到了**，别随意改名或移动。

### iPhone

iPhone 的「文件」App 点 HTML 通常只能预览、跑不了 JS，所以更推荐方案二。

如果一定要用本地文件，可以装 **Documents by Readdle** 之类的 App 打开该 HTML，或在「文件」里长按分享给支持本地网页的浏览器。

---

## 方案二：传到网上，手机浏览器访问（推荐，体验最好）

解压 `工作台-托管版.zip` 得到 `dist-web/` 文件夹（里面是 `index.html` + `assets/` + `favicon.svg`）。

### 2.1 免费静态托管（选一个，5 分钟搞定）

| 平台 | 操作要点 |
| --- | --- |
| **Netlify Drop** | 打开 `app.netlify.com/drop` → 把 `dist-web` 文件夹整个拖进去 → 立即得到链接 |
| **Vercel** | 注册 → 新建项目 → 拖入 `dist-web` → 得到 `xxx.vercel.app` |
| **Cloudflare Pages** | 创建项目 → 上传 `dist-web` → 得到 `xxx.pages.dev` |
| **GitHub Pages** | 把 `dist-web` 内容推到仓库 `gh-pages` 分支 → 设置里开启 Pages |

> 不需要任何路由重写配置，直接上传即可。上传时注意是**上传文件夹里的内容**，不是外层文件夹本身。

### 2.2 自己的服务器 / 宝塔 / 群晖 NAS

把 `dist-web` 里的**全部文件**上传到网站根目录（或任意子目录如 `/workbench/`），访问对应网址即可。Nginx 不需要额外配置。

### 2.3 添加到手机桌面（关键一步）

**iOS Safari**：打开网址 → 底部**分享**按钮 → **添加到主屏幕** → 命名「工作台」→ 添加。

**安卓 Chrome**：右上角菜单 → **添加到主屏幕 / 安装应用**。

之后从桌面图标进入，全屏无地址栏，和原生 App 的手感一样。

## 华为 Mate 60 专用步骤（HarmonyOS）

Mate 60 运行 HarmonyOS，浏览器内核基于 Chromium，用**方案一（单文件）**最省事：

1. **传输**：把 `工作台.html` 发到微信「文件传输助手」→ 手机微信里点开 → 右上角 `···` → **用其他应用打开** → 选**华为浏览器**（或 Chrome / Edge）
   - 若微信提示"无法打开"，改用「QQ → 我的电脑」或数据线拷贝到手机 `内部存储/Download`
2. **打开**：进入「文件管理」→ 浏览 → 找到 `工作台.html` → 长按 → **打开方式** → 浏览器
   - 首次可能提示"用浏览器打开文件"，确认即可
3. **添加到桌面**：华为浏览器打开后 → 底部**三横线菜单** → **添加到桌面**（部分版本叫"添加到主屏幕"）
   - 桌面上会出现「我的工作台」图标，之后点图标直接进入，全屏无地址栏

### 华为设备注意事项

| 事项 | 说明 |
| --- | --- |
| **纯净模式** | HarmonyOS 的纯净模式对本地 HTML 无影响，可放心 |
| **文件位置别动** | 数据按文件路径隔离，**移动或重命名文件会导致数据看起来丢失**，建议固定在 `Download` 或「文档」目录 |
| **省电策略** | 长期不用可能被系统清理缓存。建议每周用「更多 → 导出备份」存一份 JSON |
| **深色模式** | 应用内「外观设置 → 跟随系统」会跟随 HarmonyOS 的深色模式自动切换 |
| **状态栏颜色** | 已适配，切换主题时状态栏颜色会同步变化 |
| **屏幕刷新率** | Mate 60 支持 120Hz，应用的动画（页面切换、打卡反馈）会自动跑满 |

## 方案三：局域网访问开发服务器（只适合临时调试）

手机和电脑连同一个 Wi-Fi，电脑上运行：

```bash
cd frontend && pnpm dev --host
```

终端会打印形如 `http://192.168.1.23:5173` 的地址，手机浏览器输入即可。
缺点：电脑关机就没了，数据也和正式版不互通，不适合日常用。

## 外观设置（调色）

入口：**更多 → 外观设置**，或直接访问 `#/appearance`。

### 能调什么

| 项目 | 范围 | 说明 |
| --- | --- | --- |
| **配色方案** | 8 套预设 | 暖橙珊瑚 / 玫瑰粉 / 琥珀金 / 青竹绿 / 湖水青 / 深海蓝 / 薰衣草 / 陶土灰 |
| **主色调** | 色相 0°–360° | 拖动滑块，全站主色实时变化 |
| **饱和度** | 55%–150% | 越低越素雅，越高越鲜明 |
| **显示模式** | 浅色 / 深色 / 跟随系统 | 「跟随系统」会跟随手机深浅色自动切换 |
| **卡片圆角** | 0%–170% | 0% 为直角，170% 为大圆角 |
| **字号大小** | 90%–115% | 字小可以调大 |

底部有「恢复默认外观」一键还原。

### 实现说明

配色不是简单换一个色值，而是由**色相**驱动整套色板：主色、强调色、次要色、导航高亮、状态栏颜色
都从同一个色相推导，所以无论换成什么颜色，明暗对比和层次感都保持一致，不会出现看不清的情况。

- 主题保存在 `localStorage` 的 `wb.v1.theme`
- 刷新、切页、退出重进都会保持
- 首屏会在样式加载前先套用主题（`index.html` 内联脚本），**不会闪白**
- 深色模式单独做了变量覆盖，不是简单反色，护眼且层次清晰

## 怎么变成带 App 图标的桌面应用

工作台已经配置好 **PWA（渐进式 Web 应用）**，可以像真 App 一样装在桌面上：有专属图标、独立窗口、没有浏览器地址栏。

### 前提：必须通过网址访问

**图标安装只在 `https://` 网址下生效**，本地文件（`file://`）不行。所以先按上面的「方案二」把应用托管到一个网址（Netlify / Vercel 均可）。

> 原因：浏览器出于安全限制，只有在 https 环境下才允许注册 Service Worker 和安装 PWA。

### 华为 Mate 60（HarmonyOS）安装步骤

1. 用**华为浏览器**打开你的应用网址（如 `https://xxx.netlify.app`）
2. 等页面加载完，底部会弹出提示「**添加至桌面**」，直接点
3. 若没弹出：点底部**三横线菜单** → **添加到桌面** → 确认
4. 回到桌面，就能看到「**工作台**」图标了

打开后是全屏的，没有地址栏，和原生 App 一样。

### iPhone 安装步骤

务必用 **Safari** 打开（Chrome 不行）：

1. Safari 打开应用网址
2. 点底部**分享**按钮（方框带向上箭头）
3. 滑动找到 **添加到主屏幕**
4. 命名「工作台」→ 添加

### 全屏显示（去掉地址栏）

安装后的显示模式已在 manifest 中设为 **`fullscreen`**，并提供降级链
`["fullscreen", "standalone", "minimal-ui"]`——华为浏览器若不支持真全屏，会自动退到 standalone，
同样没有地址栏，只是保留状态栏。

效果对比：

| 方式 | 地址栏 | 工具栏 | 体验 |
| --- | --- | --- | --- |
| 浏览器直接打开 | 有 | 有 | 普通网页 |
| 添加到桌面后打开 | 无 | 无 | 像 App，全屏 |

> 关键：**必须从桌面图标进入**。在浏览器地址栏里打开，无论怎么配置都还是有地址栏的。

#### 安全区域适配（刘海 / 手势条）

全屏后内容会顶到状态栏下方，为此已做适配：

- `viewport-fit=cover` 让页面延伸到屏幕边缘
- 顶部内边距自动加上 `env(safe-area-inset-top)`（避开刘海/状态栏）
- 底部导航自动加上 `env(safe-area-inset-bottom)`（避开手势条）
- 全屏模式下禁用橡皮筋过度滚动，手感更接近原生

#### 怎么确认当前是不是全屏模式

进「更多」页，底部会显示当前状态：

- `App 模式 · Fullscreen` — 已全屏
- `App 模式 · Standalone` — 无地址栏但保留状态栏
- `浏览器模式` — 还在浏览器里，需要添加到桌面

「更多」页还会根据你的设备自动显示对应的安装步骤（华为 / iPhone / 安卓 / 电脑）。

### 关于图标

图标是专门设计的：暖橙珊瑚渐变底 + 日历勾选图形，和应用主题一致。

已提供多套规格以适配不同系统：

| 文件 | 用途 |
| --- | --- |
| `icon-192.png` / `icon-512.png` | 安卓 / 鸿蒙桌面图标（必需 PNG，SVG 在华为上不可靠） |
| `icon-512.png`（maskable） | 支持系统自适应裁切，圆形/方形桌面都不变形 |
| `apple-touch-icon.png` | iOS 添加到主屏幕专用（需 180×180 PNG） |
| `icon.svg` | 浏览器标签页图标，任意缩放都清晰 |

图标采用**满幅方底**设计，由系统自动裁圆角——这是移动端图标的标准做法，比预裁圆角效果更自然。

### 换了配色，图标会变吗

不会。桌面图标是静态图片，固定为暖橙珊瑚配色。应用内部的配色变化不影响桌面图标。

### 如果桌面图标显示成网页截图

说明浏览器没读到 manifest。检查：

1. 是否用 `https://` 访问（`http://` 除 localhost 外都不行）
2. 是否把 `manifest.webmanifest`、`icon-192.png`、`icon-512.png` 一起上传了
3. 删除旧图标重新添加一次

## 重要：数据存在哪里？

数据保存在**浏览器的 localStorage**，跟着「域名 + 浏览器」走。三个必须知道的点：

1. **换浏览器 / 换设备不同步**。手机和电脑各存各的。
2. **清理浏览器数据会丢**。建议每周用「更多 → 导出备份」存一份 JSON 到网盘，换设备时导入即可迁移。
3. **不同打开方式，数据互相独立**：

| 打开方式 | 数据归属 |
| --- | --- |
| 单文件（`file://`） | 该文件的路径 |
| 线上网址（`https://`） | 该域名 |
| 局域网 IP | 该 IP:端口 |

> 选定一种方式后就别频繁切换，否则会"看起来数据没了"。

### 防止被系统清理

- 别用「无痕 / 隐私模式」
- 添加到主屏幕后从图标进入，比每次从文件管理器打开更稳定
- 定期导出备份（这是唯一可靠的保险手段）

## 打包命令（以后改了代码要重新生成）

```bash
cd frontend

pnpm build:web     # 生成可托管的静态包 → ../dist-web/
pnpm build:single  # 生成单文件 → ../工作台.html
```

命令已写进 `frontend/package.json`。

> `build:single` 会先做一次 IIFE 库模式构建，再把 JS/CSS 内联进 HTML。
> 打包脚本 `scripts/bundle-single.mjs` 里用了**函数式 replace**和**完整性自检**——
> 因为 JS 产物中含 `$$typeof`、`"$&/"` 这类片段，若直接用字符串替换会被 `$` 语义改写导致白屏。

## 常见问题

**Q：双击 `工作台.html` 打开是空白？**

极少数浏览器的本地文件安全策略会拦截。换 Chrome / Edge 打开；或用方案二托管。

**Q：单文件打开后数据没了？**

检查是否换了文件路径或文件名——localStorage 是按路径隔离的。

**Q：添加到主屏幕后名字/图标不对？**

名字读的是 `<title>`（当前「我的工作台 · 今日」）。想改短名，编辑 `frontend/index.html` 的 `<title>` 后重新打包。

**Q：网页版刷新会不会 404？**

不会。已统一使用 HashRouter，地址形如 `...#/todos`，刷新、分享链接都正常。

**Q：想要真正的独立 App（不依赖浏览器）？**

已经配好了！安卓工程在 `frontend/android/`，用 Android Studio 打开即可构建 APK，
详见 [打包成安卓App.md](./打包成安卓App.md)。

打包后的 APK 是真正的原生应用：桌面图标、无需浏览器、不依赖网址、可离线使用。
注意 **App 数据与网页版互相独立**，需用「更多 → 导出/导入备份」手动迁移。
